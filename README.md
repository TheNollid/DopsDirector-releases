# Dops Director downloads

Dops Director is the Derpa Dops crew's Windows app for planning episodes, recording together, sending footage, finding and cutting the best moments across every POV, cleaning the copy, and delivering an editor package.

**Get it:** download `DopsDirector_Setup.exe` from the [latest release](https://github.com/TheNollid/DopsDirector-releases/releases/latest) and run it.

**Updates install themselves.** The app checks here, downloads a new version in the background and installs it once nothing is recording, sending or being analysed. **Settings → Updates & Version → Check for updates** installs it straight away. If you're on 1.1.6 or older, install the latest version by hand once.

**First time:** setup walks you through your name, folders and drives, OBS tracks, add-ons and the crew passphrase, then offers a tour. Everything is explained in **Guide** in the app.

Source code and development live in a private repository.
